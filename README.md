# Mi rutina · demostración educativa

Prototipo interactivo para una ponencia. Utiliza solo datos ficticios y no es una aplicación para pacientes ni una guía clínica.

Incluye una cuenta atrás simulada, calendario, gráfica de ejemplo, bienestar, preguntas y una vista de resumen ficticio. Es adaptable a móviles y ordenadores, y puede añadirse a la pantalla de inicio.

Los datos introducidos viven únicamente en la memoria de la página y desaparecen al recargarla o cerrarla. No introduzca nombres ni información real de pacientes. Los botones de copia y exportación son acciones locales iniciadas por el usuario.

Tras una primera carga con conexión, la aplicación puede guardar sus archivos en la caché del navegador para abrirse sin conexión, si este permite esa función. Los datos de la sesión no se guardan en dicha caché.
